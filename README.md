This proyect is an organizer for homeworks of students that have a hard time to focus on their activity, either it being they don't know which to prioritize or them not being able to concentrate.
Through it students place their homeworks with their due dates, complexity, priority or importance and the name of the work.
For this code to be able to run you need to have the librearies tkcalendar and tkinter, tkcalendar being the only one you need to download. After that go to Calendariointento2 hit the play button
The program will show a calendar, text entry, two lists of options, and a button to create the homework which will then be displayed as a list with the one that the user should be doing going first, in the next update there will be a button to erase or mark homeworks as done.
At this moment the features in the program will help by showing the students what they should start working on or should prioratize, with this we offer students with specific conditions such as ADHD, a general lack of discipline, or motivation a way to organize or not be as lost as to which activity they should do.
