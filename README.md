Este proyecto es un organizador para las tareas de los estudiantes. 
A travez de el ponen sus actividades junto con fecha de entrega, 
complejidad, prioridad o importancia y nombre.
Para poder correr este codigo ocupas las librerias tkcalendar y tkinter, 
tkcalendar deberia ser la unica que se ocupa instalar. Despues ve al archivo 
Calendariointento2 y haz click en el boton play.
